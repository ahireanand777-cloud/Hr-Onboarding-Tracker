# HR Onboarding Tracker & Dashboard

## Project Description
An Excel-based HR operations project designed to track employee onboarding activities, monitor document verification, and identify overdue tasks.

## Key Features
- Employee master database with unique employee IDs.
- Onboarding task tracking with status and due dates.
- Document submission and verification tracking.
- Overdue task and upcoming deadline monitoring.
- Dashboard showing onboarding progress by department and task owner.

## Tools Used
- Microsoft Excel
- Excel formulas and functions
- Data validation and dropdown lists
- Conditional formatting
- Charts and dashboard reporting

## Purpose
This project demonstrates practical Excel skills for HR operations, employee onboarding, documentation tracking, and routine reporting.
